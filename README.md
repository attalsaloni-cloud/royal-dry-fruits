# Royal Dry Fruits 🛒

A Django-based E-commerce web application for purchasing dry fruits online.

## 🚀 Features
- Browse dry fruit products
- Category management
- Shopping cart functionality
- Admin panel integration

## 🛠️ Built With
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite3
